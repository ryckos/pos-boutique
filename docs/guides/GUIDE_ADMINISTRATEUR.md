# Guide de l'administratrice (la patronne)

Ma Boutique POS — version 1.0.0-rc.1

## L'essentiel

- Vous avez accès à **tout**. Pour les produits, le stock, les achats et les rapports : suivez le **guide du gérant**.
- Ce guide couvre ce que **vous seule** pouvez faire : réglages, comptes, journal, sauvegardes.
- **Bouton ?** à côté du titre de chaque page : il explique les icônes.

---

## 1. Premier démarrage (une seule fois)

1. Ouvrez l'application.
2. Tapez votre nom.
3. Choisissez votre code à 4 chiffres, deux fois. **Ne le donnez à personne.**

## 2. Régler la boutique

1. Menu **Paramètres**.
2. Crayon **Boutique et ticket** : nom, adresse, NIF, message du bas du ticket.
3. Crayon **Stock** : nombre de jours pour surveiller les péremptions.
4. Crayon **Caisse** : remise maximale qu'une caissière peut faire seule (vide = toujours le code du gérant).
5. Enregistrez chaque groupe.

## 3. Créer un compte pour un employé

1. Menu **Comptes utilisateurs** → « Créer un compte ».
2. Nom, rôle (Caissier ou Gérant), un code **provisoire** à 4 chiffres.
3. Donnez ce code à l'employé : à sa première connexion, il choisira le sien.

## 4. Un employé a oublié son code

1. Menu **Comptes utilisateurs**.
2. Sur son compte : icône **clé**.
3. Tapez un nouveau code provisoire et donnez-le-lui.

**Bon à savoir** : cela débloque aussi son compte s'il était bloqué.

## 5. Changer le rôle d'un employé

1. Sur son compte : icône **personne**.
2. Choisissez le nouveau rôle, validez.

## 6. Un employé quitte la boutique

1. Sur son compte : icône **cercle barré**.
2. Tapez le motif, validez.
3. Il ne peut plus se connecter. Son historique reste.

**Bon à savoir** : vous ne pouvez pas désactiver votre propre compte.

## 7. Changer votre code

1. Menu **Mon code**.
2. Code actuel, puis le nouveau deux fois.

## 8. Voir qui a fait quoi (journal)

1. Menu **Journal des opérations** : les 7 derniers jours.
2. Filtrez par personne, par action, par dates.
3. « Afficher plus » pour remonter plus loin.
4. « Exporter » pour l'avoir dans Excel.

Vous y trouvez notamment : remises, annulations, retours, changements de prix, clôtures, ouvertures du tiroir, comptes, réglages.

## 9. Sauvegardes

**Choisir la clé USB** (une fois)
1. Branchez la clé.
2. Menu **Sauvegardes** → « Choisir la clé USB » → choisissez son dossier.
3. Laissez la clé branchée. Emportez-la hors de la boutique une fois par semaine, rebranchez-la le lendemain.

**Sauvegarder tout de suite** : « Sauvegarder maintenant ».

**Surveiller** : la date de la dernière sauvegarde est en haut de la page. Un message apparaît si elle a plus de 2 jours.

## 10. Restaurer une sauvegarde

**Attention** : tout ce qui a été fait après la sauvegarde choisie disparaît. **Ne le faites qu'avec le technicien.**

1. Menu **Sauvegardes**.
2. Sur la sauvegarde choisie : icône **flèche circulaire** (Restaurer). Ou « Restaurer depuis un fichier » pour une sauvegarde de la clé USB.
3. Lisez l'avertissement, cochez « J'ai compris ».
4. Validez : l'application redémarre. Tout le monde se reconnecte.

## 11. Règles de sécurité

- Gardez votre code secret. Donnez le rôle administrateur à vous seule.
- Un employé part : désactivez son compte le jour même.
- Consultez le journal régulièrement.
- Vérifiez chaque semaine qu'une sauvegarde récente est sur la clé USB.
